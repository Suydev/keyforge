Why this exists read-only explanation

Without egress rotation, every key reaches the provider from one device IP. That is the pattern Cloudflare answers with an HTML 502/524 interstitial — which appears in the Errors tab as UPSTREAM. Rotating egress makes the traffic look like many clients. If every proxy is cooling, the gateway connects directly rather than failing your request.
